# ESG dentro das E-commerces (nome a definir)

## Sobre nosso projeto

Este projeto tem como objetivo ressignificar a importância das práticas de ESG
para pequenas e médias empresas que atuam no comércio eletrônico.

A proposta é tornar o ESG mais simples e acessível para os pequenos
e-commerces, mostrando como práticas ambientais, sociais e de governança podem
ser aplicadas no dia a dia e contribuir para o desenvolvimento do negócio.

### 2. Registro e acompanhamento de bugs — Issue #2

A Issue #2 foi criada para documentar as verificações realizadas nas funcionalidades do Ecomply, identificar possíveis problemas e acompanhar a qualidade da aplicação.

Os testes foram realizados tanto na interface do sistema quanto no ambiente de desenvolvimento Django.

#### Resumo dos testes realizados

| Categoria | Quantidade de verificações | Resultado |
|---|:---:|---|
| Cadastro e autenticação | 4 | Aprovadas |
| Perfil do usuário | 3 | Aprovadas |
| Formulário de feedback | 3 | Aprovadas |
| Navegação e interface | 3 | Aprovadas |
| Servidor e banco de dados | 3 | Aprovadas |
| **Total** | **16** | **16 verificações concluídas** |

#### Testes de cadastro e autenticação

Foram verificados:

- Cadastro com e-mail já existente.
- Cadastro com e-mail novo.
- Validação de campos obrigatórios.
- Login com credenciais válidas e inválidas.
- Funcionamento do logout.
- Mensagens de erro nos formulários.

#### Testes de perfil e feedback

Foram verificados:

- Carregamento das informações do usuário.
- Edição e persistência dos dados pessoais.
- Restrição de acesso às páginas protegidas.
- Envio de avaliações.
- Validação dos campos obrigatórios.
- Armazenamento dos feedbacks no banco de dados.

#### Testes de navegação e interface

Foram verificados:

- Funcionamento dos links e redirecionamentos.
- Alternância entre modo claro e escuro.
- Persistência do tema selecionado.
- Adaptação das páginas para visualização em dispositivos móveis.

#### Testes de servidor e banco de dados

Foi executado o comando:

`python manage.py check`

Resultado obtido:

`System check identified no issues (0 silenced).`

Também foi utilizado o comando:

`python manage.py showmigrations`

As migrações listadas no ambiente local estavam aplicadas corretamente.

Além disso, foram verificadas as principais páginas da aplicação publicada no Render, sem erros visíveis nos cenários testados.

### 3. Resultados e conclusão

As 16 verificações previstas foram concluídas sem bugs confirmados nos cenários testados.
